# Bayanihan

Bayanihan is a Unity project.

## Requirements

- Unity Editor `6000.3.9f1`

## Open the project

1. Open Unity Hub.
2. Select **Add project from disk** and choose this project folder.
3. Open the project with Unity `6000.3.9f1`. Unity will resolve the packages listed in `Packages/manifest.json`.
4. Open **Assets/Scenes/Loadout.unity** to start, then continue to **Assets/Scenes/Gameplay.unity**.

Both scenes are included in the project's Build Settings.
